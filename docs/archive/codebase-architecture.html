四、关键数据流

▶ 播放一条歌（网络歌曲懒解析）

UI 点击Actions 回调→ PlayerViewModelplayQueue/playSong→ PlayerManagerbuildMediaItem
setMediaItems+prepare→ ExoPlayer（PlaybackService 注册）

streamUrl 为空的网络歌曲：onMediaItemTransition(AUTO) → onNeedResolveStreamUrl 回调 → ViewModel 解析（Meting/Jamendo/百度流工厂）→ replay；播放出错且未重试过 → 重解析一次，仍失败自动跳下一首（防死循环）

▶ K 歌 HQ 人声分离 N-4

VocalSeparationViewModelsetSeparationMode(HQ)→ HqSeparationOrchestratorenableHighQualityRemoval→ resolveInputPath本地文件或下载→ DemucsSeparatorONNX 分离(IO)→ PlayerHost切伴奏文件

伴奏已缓存则直接切换；失败/超时/OOM 一律回退 FAST 模式 DSP（SpectralMaskProcessor）；原唱文件入 AccompanimentCache 供切回

▶ 多源曲库合并

LibraryScreen五 Tab 浏览→ MainViewModelmergedAlbums/mergedArtists→ MusicMergerNAS+本地+百度 三源合并→ UnifiedSongRow来源徽章渲染

百度索引经 baiduFileIndexCache 属性委托；NAS 收藏分支 toggleNasFavorite 留在 MainViewModel（依赖 _favoriteIds 状态）

▶ 后端切换（连接生命周期）

ServerConnectScreen输入地址凭据→ ServerViewModeltestConnection（一次性适配器，不动当前状态）→ BackendRegistry切换活动适配器→ onConnected 回调loadLibrary+恢复队列

共享 OkHttp 池：适配器 close() 只清认证态，不 shutdown 全局线程池——连续切换不累积资源 R-6
