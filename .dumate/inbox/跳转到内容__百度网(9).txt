接口描述
本接口用于创建文件夹。

同时，本接口也是上传文件的创建文件接口，详情参见《上传/创建文件》。

 

权限说明
本接口必须经过用户授权后才可正常使用，具体的授权流程和机制的可参考《使用入门 > 接入授权》。

 

注意事项
执行示例代码时，请将示例代码中的access_token参数值替换为自行获取的access_token
 

请求结构
POST /rest/2.0/xpan/file?method=create&access_token=xxx HTTP/1.1
Host: pan.baidu.com

 

请求参数
参数名称	类型	是否必填	示例	参数位置	描述
method	string	是	create	URL参数	本接口固定为create
access_token	string	是	12.a6b7dbd428f731035f771b8d15063f61.86400.1292922000-2346678-124328	URL参数	接口鉴权认证参数，标识用户
path	string	是	/apps/appName/mydir	RequestBody参数	创建文件夹的绝对路径，需要urlencode
isdir	string	是	1	RequestBody参数	本接口固定为1
rtype	int	否	1	RequestBody参数	文件命名策略，默认0
0 为不重命名，返回冲突
1 为只要path冲突即重命名
local_ctime	int	否	1596009229	RequestBody参数	客户端创建时间(精确到秒)，默认为当前时间戳
local_mtime	int	否	1596009229	RequestBody参数	客户端修改时间(精确到秒)，默认为当前时间戳
mode	int	否	1	RequestBody参数	上传方式
1 手动、2 批量上传、3 文件自动备份
4 相册自动备份、5 视频自动备份
 

响应参数
参数名称	类型	描述
errno	int	错误码
fs_id	uint64	文件在云端的唯一标识ID
category	int	分类类型, 6 文件夹
path	string	上传后使用的文件绝对路径
ctime	uint64	文件创建时间
mtime	uint64	文件修改时间
isdir	int	是否目录，0 文件、1 目录
 

错误码
错误码	错误描述	排查方向
-7	文件或目录名错误或无权访问	无
-8	文件或目录已存在	无
-10	云端容量已满	无
更多错误码请参考《开发者须知 > 错误码》中“公共错误码”部分。

java示例
Terminal window
import java.io.*;
import java.net.HttpURLConnection;
import java.net.URL;

public class HttpPostRequestExample {
    public static void main(String[] args) {
        try {
            URL url = new URL("https://pan.baidu.com/rest/2.0/xpan/file?method=create&access_token=12.a6b7dbd428f731035f771b8d15063f61.86400.1292922000-2346678-124328");
            HttpURLConnection httpConn = (HttpURLConnection) url.openConnection();
            httpConn.setRequestMethod("POST");
            httpConn.setDoOutput(true);

            OutputStreamWriter writer = new OutputStreamWriter(httpConn.getOutputStream());
            writer.write("path=/apps/test/mydir&isdir=1&rtype=1");
            writer.flush();
            writer.close();
            httpConn.getOutputStream().close();

            int responseCode = httpConn.getResponseCode();
            System.out.println("Response Code : " + responseCode);
            BufferedReader in = new BufferedReader(new InputStreamReader(httpConn.getInputStream()));
            String inputLine;
            StringBuffer response = new StringBuffer();
            while ((inputLine = in.readLine()) != null) {
                response.append(inputLine);
            }
            in.close();
            System.out.println(response.toString());
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}
