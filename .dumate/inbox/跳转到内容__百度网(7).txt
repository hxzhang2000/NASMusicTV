接口描述
本接口用于将用户存储在网盘的云端文件下载到本地。文件下载分为三个阶段：先通过获取文件列表取得文件 fs_id，再通过查询文件信息并将 dlink 设为 1 获取下载地址，最后对返回的 dlink 发起 GET 请求。第二阶段依赖第一阶段返回结果，第三阶段依赖第二阶段返回结果，三个阶段串行完成后文件下载到本地。

文件下载三阶段流程

权限说明
所有 API 的安全认证一律采用百度 OAuth 2.0 鉴权认证机制。百度 OAuth 2.0 鉴权认证机制的详细内容参见《开发者须知 > 接入流程》。

第三方应用在网盘只能拥有一个文件夹用于存储、上传和下载文件，该文件夹必须位于 /apps 目录下，apps 下的文件夹名称为申请接入时填写的产品名称。例如申请接入的产品名称为“云存储”，那么该文件夹为 /apps/云存储，用户看到的文件夹为 /我的应用数据/云存储。

鉴权详情：接入授权。

请求结构
源接口请求
项目	内容
HTTP Method	GET
HTTP URL	https://pan.baidu.com/rest/2.0/xpan/file?method=download
固定查询参数	method=download、check_blue=1、esl=1
dlink 下载请求
项目	内容
HTTP Method	GET
HTTP URL	<DLINK_URL>&access_token=<ACCESS_TOKEN>
Host	以 dlink 返回的实际域名为准
DLINK 下载地址通过查询文件信息接口返回
header参数
参数名称	类型	是否必填	描述
User-Agent	string	是	示例：pan.baidu.com；请求头部，固定使用 pan.baidu.com。
Range	string	否	示例：bytes=0-499；用于断点续传，下载文件指定范围的数据。

错误码
HTTP 状态	业务码	含义	排查 / 修复	是否可重试
200	0	请求成功	按响应 Content-Type 读取文件。	否
200	20011	路径不在允许访问范围内	确认路径位于 /apps/<APP_NAME>/，并检查应用目录权限。	否
200	31045	access_token 校验未通过	刷新 Token，并确认用户已授权网盘权限。	否

请求示例
源接口请求
Terminal window
curl --get 'https://pan.baidu.com/rest/2.0/xpan/file' \
--data-urlencode 'method=download' \
--data-urlencode 'access_token=<ACCESS_TOKEN>' \
--data-urlencode 'app_id=<APP_ID>' \
--data-urlencode 'user_id=<USER_ID>' \
--data-urlencode 'path=/apps/<APP_NAME>/<FILE_NAME>' \
--data-urlencode 'check_blue=1' \
--data-urlencode 'esl=1'

dlink 下载请求
cURL
Python
Java
Terminal window
curl --location --get '<DLINK_URL>' \
--data-urlencode 'access_token=<ACCESS_TOKEN>' \
-H 'User-Agent: pan.baidu.com'

响应示例
源接口返回失败或封装信息时可能为 JSON：

{
  "errno": 0,
  "newno": "",
  "request_id": 1234567890,
  "server_time": 1596078019,
  "show_msg": "",
  "data": {
    "error_code": 0,
    "request_id": 1234567890
  }
}

成功时响应体为文件二进制：

<FILE_BINARY_CONTENT>

失败时可能返回 JSON：

{
  "errno": 31360,
  "show_msg": "download link expired",
  "request_id": 1234567890
}

SDK获取
我们提供了 Go 版本 SDK，帮助开发者快速实现下载能力。

下载 Go 版本 SDK（download.tar.gz）。
下载后，使用 tar -zxvf *.tar.gz 命令解压。
解压后，在 download 目录下可看到如下目录结构：
.
├── demo
│   ├── download.go
│   └── file_metas.go
├── download
│   ├── download.go
│   ├── file_metas.go
│   └── types.go
└── utils
    └── util.go

其中，demo 为使用示例，可参考其中的接口参数进行调用并获取接口返回结果；download/file_metas.go 用于获取文件信息并获得下载地址 dlink；download/download.go 用于使用 dlink 地址下载文件；utils/utils.go 为发送 HTTP 请求的函数实现，供获取文件信息和下载文件调用。

注意： 目前下载 SDK 仅支持小文件下载；涉及大文件时，可参考该 demo 升级改造，加入分片下载、断点下载等能力。

注意事项
通过列表类接口获取文件的唯一标识 fs_id，例如请求获取文件列表。
通过查询文件信息获取文件下载地址，请求时将 dlink 置为 1，接口返回的 dlink 即为下载地址。
使用 dlink 时，必须拼接 &access_token=<ACCESS_TOKEN> 参数。
使用 dlink 时，必须在请求 Header 中设置 User-Agent: pan.baidu.com。
设置好请求 Header，并在 dlink 后拼接 access_token 后再进行下载。
dlink 有效期为 8 小时，过期后失效，需要重新查询文件信息获取新的地址。
dlink 可能发生 HTTP 302 跳转，客户端应允许跟随跳转并保留鉴权参数。
不允许使用浏览器直接下载超过 50 MB 的文件；超过 50 MB 的文件需使用开发者原生软件或 App 下载。
Range: bytes=0-499 表示文件起始的 500 字节；bytes=500-999 表示第二个 500 字节；bytes=-500 表示文件最后 500 字节；bytes=500- 表示文件 500 字节以后的范围。
