错误码格式
当用户访问 API 出现错误时，会返回给用户相应的错误码和错误信息，便于定位问题，并做出适当的处理。请求发生错误时通过 Response Body 返回详细错误信息，遵循如下格式：

参数名	类型	说明
errno	String	表示具体错误码。
errmsg	String	有关该错误的描述。
request_id	String	发起请求的请求 Id。
例如：

Terminal window
{
  "errno": -6,
  "errmsg": "Invalid Bduss",
  "request_id": "8889392513333350895"
}

 

错误码须知
1.一个错误码数字未必是对应一个接口的，业务多，可能存在同一个错误码数字被用在多个业务中。

2.一个错误码未必是固定一种原因，具体问题具体分析。下一段给出一些排查方向，您可以根据这些方向进行自查，帮助您解决遇到的问题。

3.每个接口下也会有一些错误码提示，您也可以进行参考。

4.如果是偶现出现的错误，建议您进行重试。
