接口描述
本接口用于查询文件元信息，包括文件名、创建和修改时间、大小、类型、缩略图、媒体信息以及可选的下载地址 dlink。主调用方式为 method=meta，同时支持 method=filemetas 的路径批量方式；线上页面当前展示 method=filemetas 的 multimedia/fsids 批量方式。

权限说明
调用前请完成用户授权，并取得有效的 access_token。

鉴权详情：接入授权。

硬件设备文件场景需要传入 device_id。from_apaas=1 仅适用于已购买对应极速流量权益的应用；如需购买极速流量权益服务，可联系商务合作邮箱 ext_mars-union@baidu.com 咨询。

HTTP Method	GET
HTTP URL	https://pan.baidu.com/rest/2.0/xpan/file?method=meta
固定查询参数	method=meta

项目	内容
HTTP Method	POST
HTTP URL	https://pan.baidu.com/rest/2.0/xpan/file?method=filemetas
固定查询参数	method=filemetas
fsids 批量请求（method=filemetas）
项目	内容
HTTP Method	GET
HTTP URL	https://pan.baidu.com/rest/2.0/xpan/multimedia?method=filemetas
固定查询参数	method=filemetas
请求参数
单文件请求参数（method=meta）
参数名称	类型	是否必填	描述
method	string	是	固定值 meta，指定查询文件元信息。
access_token	string	是	OAuth 2.0 Token。
path	string	是	文件的网盘绝对路径，需 URL 编码，例如 /apps/<APP_NAME>/<FILE_NAME>。
dlink	int	否	传 1 时返回下载地址。
thumb	int	否	传 1 时返回图片或视频缩略图地址。
extra	int	否	传 1 时返回图片拍摄时间、宽高等信息。
needmedia	int	否	传 1 时返回视频时长等媒体信息。
web	int	否	传 1 时返回 Web 展示字段。
路径批量请求参数（method=filemetas）
参数名称	类型	是否必填	描述
method	string	是	示例：filemetas；固定值 filemetas，指定本次操作为批量查询文件元信息。
access_token	string	是	示例：<ACCESS_TOKEN>；用户授权凭证，标识访问哪个用户的网盘。
target	array	是	示例：["/apps/<APP_NAME>/<FILE_NAME>"]；文件路径的 JSON 数组，需 URL 编码，支持一次查询多个文件。
dlink	int	否	示例：1；是否返回下载直链：1 返回，0 不返回，默认 0。
blocks	int	否	示例：0；是否返回文件分片的 MD5 列表 block_list：1 返回，0 不返回，默认 0。
media	int	否	示例：0；是否返回视频时长等媒体信息：1 返回，0 不返回，默认 0。
web	int	否	示例：1；是否返回额外的 Web 端展示字段。
fsids 批量请求参数（method=filemetas）
参数名称	类型	是否必填	描述
method	string	是	示例：filemetas；本接口固定为 filemetas。
access_token	string	是	示例：<ACCESS_TOKEN>；OAuth 2.0 Token。
fsids	array	是	示例：[123456789012345,123456789012346]；文件 ID 数组，元素为 uint64，最多 100 个；作为 JSON 数组 URL 编码。
dlink	int	否	示例：0；是否需要下载地址：0 否，1 是，默认 0。获取到 dlink 后参考下载文档进行下载。
thumb	int	否	示例：0；是否需要缩略图地址：0 否，1 是，默认 0。
extra	int	否	示例：0；图片是否需要拍摄时间、原图分辨率等额外信息：0 否，1 是，默认 0。
needmedia	int	否	示例：0；视频是否需要展示时长信息：0 否，1 是，默认 0；返回 duration，单位为秒并向上取整。
detail	int	否	示例：0；视频是否需要展示长宽等信息：0 否，1 是，默认 0；返回信息在 media_info 字段内。
path	string	否	示例：/123-571234；查询共享目录或专属空间内文件时使用。共享目录格式为 /uk-fsid，专属空间格式为 /_pcs_.appdata/xpan/；此参数生效时不会返回正常目录下文件的信息。
device_id	string	否	示例：<DEVICE_ID>；设备 ID，硬件设备场景必传。
from_apaas	int	否	示例：1；为下载地址 dlink 附加极速流量权益；该权益为付费权益，否则此参数无效。

请求示例
cURL
Python
Java
单文件请求（method=meta）

Terminal window
curl --get 'https://pan.baidu.com/rest/2.0/xpan/file' \
--data-urlencode 'method=meta' \
--data-urlencode 'access_token=<ACCESS_TOKEN>' \
--data-urlencode 'path=/apps/<APP_NAME>/<FILE_NAME>' \
--data-urlencode 'dlink=1'

路径批量请求（method=filemetas）

Terminal window
curl -X POST 'https://pan.baidu.com/rest/2.0/xpan/file' \
--data-urlencode 'method=filemetas' \
--data-urlencode 'access_token=<ACCESS_TOKEN>' \
--data-urlencode 'target=["/apps/<APP_NAME>/<FILE_NAME>"]' \
--data-urlencode 'blocks=0' \
--data-urlencode 'dlink=1' \
--data-urlencode 'media=0'

fsids 批量请求（method=filemetas）

Terminal window
curl --location --get 'https://pan.baidu.com/rest/2.0/xpan/multimedia' \
--data-urlencode 'method=filemetas' \
--data-urlencode 'access_token=<ACCESS_TOKEN>' \
--data-urlencode 'fsids=[123456789012345,123456789012346]' \
--data-urlencode 'thumb=1' \
--data-urlencode 'dlink=1' \
--data-urlencode 'extra=1' \
--data-urlencode 'needmedia=1' \
--data-urlencode 'detail=1' \
-H 'User-Agent: pan.baidu.com'

SDK获取
我们提供了 Go 版本 SDK，帮助开发者快速实现文件元信息查询能力。

下载 Go 版本 SDK（download.tar.gz）。
下载后，使用 tar -zxvf *.tar.gz 命令解压。
解压后，在 download 目录下可看到如下目录结构：
├── demo
│   ├── download.go
│   └── file_metas.go
├── download.go
├── file_metas.go
└── types.go

其中，demo 为使用示例，可参考其中的接口参数进行调用并获取接口返回结果；download/file_metas.go 用于获取文件信息；download/download.go 用于将文件下载至本地，如果不需要下载则无需关注此步骤。

注意事项
执行请求示例代码时，请将示例代码中的 access_token 参数替换为自行获取的 access_token。
fsids 批量方式最多包含 100 个文件 ID；批量查询时先判断顶层 errno，再按 list 条目处理结果。
只有设置 dlink=1 才返回下载直链，直链通常有效 8 小时；下载时需携带 User-Agent: pan.baidu.com，详见下载。
fsids 批量方式只有设置 thumb=1 且文件支持缩略图时才返回 thumbs；extra=1 用于图片信息，needmedia=1 和 detail=1 用于视频信息。
路径批量方式使用 target 路径数组，blocks=1 返回 block_list，media=1 返回视频时长等媒体信息。
查询共享目录时，path 用于指定共享目录或专属空间，不是普通文件路径；设置该参数后不会返回正常目录下文件的信息。
