# NAS Music TV

一款开源的 Android TV 音乐播放器：聚合 NAS（Jellyfin / Navidrome / Subsonic）、网络音乐与百度网盘多音乐源，支持逐字卡拉OK歌词、K 歌伴奏、MTV 音乐视频、天气电台等电视专属体验。

[![Release](https://img.shields.io/github/v/release/hxzhang2000/NASMusicTV?color=blue&label=Release)](https://github.com/hxzhang2000/NASMusicTV/releases)

## 功能特性

### 首页仪表盘
- **首页概览**：启动即见当前播放状态、最近播放记录、实时天气与均衡器动态预览
- **播放统计**：自动记录每首歌的播放次数与最后播放时间，驱动首页"最近播放"列表

### 音乐播放
- **NAS 音乐播放**：连接 Jellyfin / Navidrome / Subsonic 后端，播放 NAS 中的音乐
- **网络音乐搜索**：通过 Meting-API 在线搜索网易云音乐，独立于 NAS 后端
- **网络歌曲播放**：302 重定向解析真实 mp3 URL，播放链接实时解析不缓存
- **播放模式**：顺序播放、单曲循环、列表循环、随机播放
- **播放队列管理**：添加、移除、清空、移动排序
- **播放队列持久化**：重启应用自动恢复上次播放队列
- **均衡器**：预设方案 + 频段增益调节
- **可视化均衡器**：实时 FFT 频谱动画，支持 ColorFlow / NeonPulse / ClassicalWave 三种视觉主题
- **人声消除（卡拉OK伴奏模式）**：实时 DSP 分离 Mid/Side 声道，切合人声频段深度衰减（保留 15%）而非完全挖空，Side 声道仅轻度削减（保留 50%）保住立体声宽度——K 歌时背景音乐完整不塌方（`VocalRemovalProcessor`）
- **K 歌模式**：播放页点"K歌"按钮进入全屏沉浸 K 歌页，双行歌词窗口逐行滚动 + 逐字平滑变色推进（逐字"前快后慢"节奏，句尾拖音自然），歌词框下缘显示整曲青色进度细线，底部工具栏随时"原唱/伴奏"切换、退出返回播放页；逐字模式与 K 歌页共用同一套双色渲染组件（`KaraokePlaybackScreen`）
- **歌曲详情面板**：当前播放歌曲的码率、采样率、编码格式等技术参数悬浮展示
- **MTV 音乐视频**：播放页「K歌」按钮旁新增 MTV 按钮，切歌时后台自动搜索 B 站 MV（三步取流：搜索->view->playurl），搜到则按钮亮起可点击进入全屏视频页（`MvPlaybackScreen`，独立 ExoPlayer + 暗色渐变遮罩 + 可开关 K 歌逐字歌词 + 上一首/下一首/切换按钮，5 秒无操作自动虚化），未搜到则置暗不可点；MV 播完自动预搜下一首无缝连播（无闪烁无混音），搜索返回多个候选可切换不同视频（2 轮后自动重搜排除已展示结果）；bvid 持久缓存跨会话复用（播完的 MV 优先，LRU 5000 条，含备份/恢复）；进入时暂停主播放器、退出时恢复（`MvSearchManager` / `BilibiliMvService` / `MvPersistentCache`）
- **播放页跳转网络搜索**：歌手名和歌曲名可聚焦（D-Pad 选中），按下确定键跳转到网络音乐搜索页并自动填入搜索词

### 网络音乐
- **在线搜索**：支持中文关键词搜索，多端点自动 fallback（Mikus / Redcha / Qijieya）
- **搜索全部播放**：搜索结果按歌手+歌名去重后一键批量播放（上限 30 首），列表内嵌逐首"加入队列"按钮
- **网络歌词**：自动获取在线歌词，失败回退到酷狗/网易云
- **网络封面**：Coil 自动跟随 302 重定向显示封面
- **歌曲收藏**：收藏网络歌曲，下次可直接播放（LRU 上限 500 条）
- **端点配置**：设置页可选择预设端点或自定义 Meting-API 端点
- **MTV 视频端点配置**：设置页网络搜索分区新增"视频端点"——预设 B站官方 API + 自定义端点（可指向自建代理/镜像），供 MTV 音乐视频搜索使用（`BilibiliMvService`）

### 天气电台
- **按心情选歌**：根据实时天气（晴/雨/雪/风/阴/夜晚）自动从 NAS 曲库和网络歌曲匹配心情电台
- **双源天气**：Open-Meteo + OpenWeatherMap 双源自动 fallback，支持未来 5 天天气预报
- **无需 NAS**：无后端连接时也能从网络端搜索匹配心情的歌曲

### 百度网盘音乐
- **百度网盘音乐播放**：设备码 OAuth 鉴权，连接百度网盘播放音乐（无需 NAS 后端）
- **文件列表与搜索**：目录浏览 + 关键词搜索（参数名 `key`），支持递归
- **音乐串流**：dlink 直链播放（补 `access_token` + `Referer` + `User-Agent` 三头）
- **歌词与封面**：侧车 LRC + 内嵌 ID3 USLT/APIC，网络匹配 fallback
- **MV 关联**：同目录同名匹配 + 歌手歌名搜索，支持 MTV 全屏播放
- **本地索引缓存**：BFS 扫描 + 60ms 节流，增量更新，首次扫描后毫秒级搜索
- **API 版本探测**：字段指纹 SHA-256 检测百度 API 静默升级，异常时一次性提示用户
- **多网盘预留**：CloudDriveType 枚举预留阿里云盘/123 网盘/夸克网盘占位，首批仅百度

### 歌词系统
- **逐行滚动歌词**：适配电视大屏
- **逐字高亮**：支持卡拉 OK 逐字变色效果，50ms 高频刷新平滑过渡
- **歌词匹配**：自动从网络匹配歌词并本地持久化缓存（LRU 保留最近 2000 首，同一首歌再次播放时零网络请求）
- **多来源获取**：MP3 内嵌、本地缓存、本地文件、网络匹配、缓存，支持来源切换
- **网络歌词持久化缓存**：用户切到网络歌词时暂存，歌曲播放完成时提交（类似 MV 缓存 `markCompleted`），下次播放自动读取并显示"缓存"来源标签
- **高亮模式记忆**：逐字/逐行选择跨页面切换保留
- **字体缩放**：播放页 +/- 按钮调节歌词字号（0.7x–1.6x），设置持久化

### 曲库浏览
- **搜索功能**：拼音首字母匹配（"zjl" 搜索 "周杰伦"）+ 子串匹配
- **艺术家 / 专辑 / 歌曲**：网格卡片浏览，点击进入详情页
- **流派 / 年代浏览**：按流派和出版年份筛选
- **收藏与最近播放**：支持收藏、播放次数统计
- **播放列表**：创建、删除、播放、管理歌曲

### 封面与显示
- **专辑封面**：支持内嵌元数据提取和在线获取
- **艺术家封面**：自动获取艺术家图片
- **多封面轮播**：歌曲/专辑/艺术家多张封面每 10 秒轮播，单张时静态显示，加载失败自动 fallback
- **网络歌词联动封面**：NAS 歌曲切换到"在线歌词"时同时获取并加入网络封面轮播
- **歌词来源标签**：显示当前歌词来源（内嵌/本地/网络/在线），点击切换
- **封面滤镜**：高斯模糊强度调节（0–25dp）+ 暗色遮罩透明度（0–100%），实时应用到播放页封面

### TV 体验
- **手机遥控（扫码控制）**：K歌/MTV 全屏页右上角显示二维码，手机扫码打开遥控页——查看/调整播放队列、搜索并添加歌曲（遥控服务器按需启动，不常驻占用端口/线程）
- **遥控器优化**：完整的 D-Pad 导航和焦点系统
- **HDMI-CEC**：支持电视遥控器媒体键控制
- **前台通知**：媒体播放通知栏，支持 play/pause/next/previous
- **多架构支持**：ARM64 / ARMv7 / x86_64

## 技术栈

- Kotlin + Jetpack Compose for TV
- Media3 / ExoPlayer 音频引擎
- OkHttp 网络层
- Coil 图片加载
- TinyPinyin 拼音转换（兼容 API 22+）

## 界面预览

- **首页仪表盘**：当前播放状态、最近播放记录、实时天气、均衡器频谱动态预览
- **播放页**：左侧专辑封面 + 右侧歌词，封面滤镜（高斯模糊 + 暗色遮罩），进度条 + 控制按钮 + 可视化频谱 + 歌曲详情面板，网络歌曲显示 NET 标识
- **曲库页**：专辑 / 艺术家 / 歌曲 / 流派 / 年代 / 收藏 / 最近播放
- **网络音乐页**：在线搜索歌曲，推荐歌单卡片行，歌单详情（Play All + 队列操作），收藏列表
- **天气电台**：按当前天气心情自动匹配歌曲，双列榜单卡片网格（封面轮播 + 换一批）
- **详情页**：专辑详情、艺术家详情（歌曲列表 + 播放全部）
- **队列页**：播放队列管理（删除、移动、清空）
- **设置页**：主题、动画、播放模式、缓存管理、均衡器、歌词缩放、封面滤镜、天气 API Key、网络音乐端点配置、MTV 视频端点配置（左侧导航栏支持遥控器滚动）
- **连接页**：Jellyfin / Navidrome / Subsonic 服务器配置

## 构建与运行

```bash
# 设置 JAVA_HOME
export JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"

# Debug APK
./gradlew assembleDebug

# Release APK
./gradlew assembleRelease

# 运行测试
./gradlew test

# 推送到电视（将 192.168.0.116 替换为你的电视 IP）
adb -s 192.168.0.116:5555 install -r app/build/outputs/apk/debug/app-debug.apk
```
